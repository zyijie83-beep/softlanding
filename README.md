# SoftLanding 安落

SoftLanding 安落中英双语官网原型，纯静态文件，无需安装依赖或构建。

## Publish with GitHub Pages

1. 将本目录中的文件和 `assets/` 一起放在 GitHub 仓库根目录并推送。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment** 选择 **Deploy from a branch**，选择发布分支和 **/(root)**。
4. 保存后，GitHub Pages 会在 Pages 设置中显示网站地址。

首页是 `index.html`，`credits.html` 列出图片来源。请保留两页旁边的 `assets/` 目录。

## 本地预览

使用任意静态文件服务器预览本目录；直接以 `file://` 打开时，浏览器可能会限制页面脚本。
